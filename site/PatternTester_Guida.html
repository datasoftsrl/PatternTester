Introduzione

Pattern Tester è un'applicazione per visualizzare e configurare pattern di test destinati a uno o più monitor. La finestra principale raccoglie i comandi nei menu e mostra, quando disponibile, l'area di configurazione del pattern selezionato.

Questa guida descrive le funzioni attualmente presenti nell'interfaccia. I nomi dei comandi seguono quelli visualizzati nei menu dell'applicazione.

Menu File

ComandoFunzione
SalvaSalva la configurazione corrente secondo le impostazioni di salvataggio.
Impostazioni...Apre la finestra delle impostazioni predefinite dell'applicazione.
EsciChiude l'applicazione.

Menu Display

Monitor

Permette di scegliere il monitor di destinazione. La selezione del monitor viene mantenuta nella configurazione.

Colonne

Definisce il numero di colonne utilizzate nella disposizione dei display. La selezione avviene tramite i valori disponibili nel menu.

Righe

Definisce il numero di righe utilizzate nella disposizione dei display.

Righe e colonne determinano la disposizione della configurazione multi-monitor. I valori selezionati vengono applicati alla visualizzazione del pattern.

Menu Pattern

Dal menu Pattern è possibile scegliere il tipo di test da visualizzare.

Geometry
Pattern geometrico con linee e opzioni geometriche.
Single Color
Visualizzazione uniforme di un singolo colore.
Gray
Pattern in scala di grigi con regolazione del livello.
Gamma
Pattern a scacchiera utilizzato per la verifica della risposta gamma.
Bars
Pattern a barre per controlli visivi sul display.
Color Bars
Barre colorate per la verifica della resa cromatica.
Gradient to Black
Gradiente verso il nero.
Two Colors Gradient
Gradiente tra due colori.
Chessboard
Pattern a scacchiera.
Phase
Pattern destinato alla verifica della fase.
Color Temperature
Pattern per la verifica della temperatura colore.
Selezionando un pattern, l'area di configurazione della finestra principale si adatta automaticamente ai parametri disponibili per quel pattern.

Menu Visualizza

Mostra Pattern

Attiva o disattiva la visualizzazione del pattern sul display.

Mostra informazioni monitor

Mostra le informazioni relative al monitor. La finestra delle informazioni può essere portata in primo piano per una consultazione immediata.

Impostazioni

La finestra Impostazioni permette di definire i valori predefiniti utilizzati dall'applicazione.

Avvio

  • Ultima configurazione: utilizza la configurazione precedente.
  • Valori predefiniti: utilizza i valori configurati nelle impostazioni.
  • Mostra automaticamente il pattern all'avvio: visualizza automaticamente il pattern all'avvio.

Valori predefiniti

  • Pattern: pattern iniziale.
  • Monitor: monitor predefinito.
  • Colonne: numero di colonne predefinito.
  • Righe: numero di righe predefinito.

Salvataggio

  • Alla chiusura
  • Ad ogni modifica
  • Solo manualmente con Salva

Configurazione dei pattern

Geometry

  • Lines: numero di linee del pattern.
  • Diagonal lines: abilita le linee diagonali.
  • Circle: abilita il cerchio.

Single Color

Permette di scegliere un colore preimpostato tra quelli disponibili, come nero, bianco, rosso, verde, blu, magenta, giallo e ciano.

Gray

Il parametro White % controlla il livello di bianco del pattern in percentuale.

Gamma

  • Gamma: valore gamma regolabile.
  • Dimensione scacchiera: numero di celle per lato.
I parametri specifici degli altri pattern vengono mostrati nell'area di configurazione della finestra principale quando il relativo pattern viene selezionato.
