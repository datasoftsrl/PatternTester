# Aspect Ratio

## Purpose

The Aspect Ratio pattern verifies that the displayed image maintains the correct geometric proportions.

Incorrect aspect ratio causes circles to appear as ellipses and squares as rectangles.

---

# Typical Uses

- Monitor setup
- Television calibration
- HDMI devices
- Media players
- Retro computers
- Game consoles

---

# Expected Result

The display should preserve:

- perfect circles
- square grids
- equal horizontal and vertical scaling

---

# Common Problems

## Horizontal Stretch

Objects appear wider than expected.

Possible causes:

- incorrect monitor settings
- GPU scaling
- television overscan

---

## Vertical Stretch

Objects appear taller than expected.

---

## Non-Uniform Scaling

Different scaling factors are applied horizontally and vertically.

---

# Professional Notes

Aspect Ratio verification should always precede geometry testing.
