# Checkerboard

## Purpose

The checkerboard pattern evaluates contrast, local dimming and pixel response.

It is particularly useful for LCD, MiniLED and OLED displays.

---

# Typical Uses

- Contrast verification
- Local dimming evaluation
- Blooming detection
- Uniformity inspection

---

# Evaluation

Observe:

- edge sharpness
- blooming
- luminance consistency
- black level

---

# Common Problems

## Blooming

Bright squares illuminate surrounding dark areas.

---

## Halo

Bright edges become visible around white regions.

---

## Poor Contrast

Black areas appear gray.

---

# Professional Notes

Perform this test in a dark environment for best results.
