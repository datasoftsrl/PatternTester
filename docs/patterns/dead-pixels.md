# Dead Pixels

## Purpose

Dead Pixel patterns help identify defective LCD, OLED and LED pixels.

The test displays uniform colors covering the entire screen.

---

# Typical Uses

- Incoming inspection
- Warranty verification
- Manufacturing QA
- Monitor acceptance testing

---

# Test Colors

Typical inspection colors:

- Black
- White
- Red
- Green
- Blue

Each color reveals different pixel defects.

---

# Common Problems

## Dead Pixel

Always black.

---

## Stuck Pixel

Remains permanently on one color.
