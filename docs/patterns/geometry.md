# Geometry Grid

## Purpose

The geometry grid verifies that the monitor reproduces straight lines with correct proportions.

---

## Typical Uses

- Aspect ratio verification
- Overscan detection
- Image centering
- Pixel mapping
- Display scaling

---

## Expected Result

The grid should appear:

- perfectly rectangular
- centered
- evenly spaced
- undistorted

---

## Common Problems

### Overscan

Outer lines disappear.

---

### Stretching

Squares become rectangles.

---

### Scaling Errors

Lines appear uneven or blurry.

---

## Professional Notes

Geometry should always be verified using the monitor native resolution.
