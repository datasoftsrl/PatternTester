# Grid Alignment

## Purpose

Grid Alignment patterns verify that image elements remain correctly aligned over the entire display area.

---

# Typical Uses

- Flat panel evaluation
- Projector installation
- Display wall setup
- Video processor verification

---

# Evaluation

Inspect:

- line spacing
- corner alignment
- edge consistency
- grid symmetry

---

# Common Problems

## Curved Lines

Usually indicate geometry distortion.

---

## Uneven Spacing

May reveal scaling artifacts.

---

## Edge Compression

Grid spacing changes near screen borders.

---

# Professional Notes

Evaluate the grid from multiple viewing positions to detect perspective errors.
