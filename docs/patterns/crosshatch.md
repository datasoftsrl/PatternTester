# Crosshatch

## Purpose

Crosshatch patterns verify geometric accuracy and image linearity.

Historically they have been widely used for CRT alignment but remain useful for digital displays.

---

# Typical Uses

- Geometry
- Convergence
- Aspect ratio
- Scaling verification

---

# Evaluation

Lines should remain:

- straight
- evenly spaced
- perpendicular

The grid should remain centered across the entire screen.

---

# Common Problems

## Barrel Distortion

Lines curve outward.

---

## Pincushion Distortion

Lines curve inward.

---

## Trapezoid Distortion

Vertical edges are no longer parallel.

---

# Professional Notes

Crosshatch evaluation should always be performed using the monitor native resolution.
