# Contrast

## Purpose

The Contrast pattern evaluates the display's ability to reproduce the difference between the darkest and brightest luminance levels.

Correct contrast adjustment maximizes image quality without losing shadow or highlight detail.

---

# Typical Uses

- Monitor calibration
- Television setup
- HDR evaluation
- Projector adjustment

---

# Evaluation

A correctly adjusted display should provide:

- deep blacks
- bright whites
- preserved highlight detail
- preserved shadow detail

---

# Common Problems

## Excessive Contrast

Symptoms:

- white clipping
- blooming
- loss of highlight detail
