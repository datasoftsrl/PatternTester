# Blooming

## Purpose

The Blooming pattern evaluates the halo effect generated by local dimming systems around bright objects displayed on dark backgrounds.

Blooming is mainly observed on:

- Full Array Local Dimming LCD
- MiniLED displays

OLED displays normally do not exhibit blooming.

---

## Typical Uses

- HDR verification
- Local dimming evaluation
- Display comparison

---

## Evaluation

Display one or more bright objects over a black background.

Observe:

- halo size
- halo intensity
- symmetry
- movement

---

## Expected Result

Bright objects should remain isolated without illuminating adjacent dark areas.

---

## Common Problems

### Large Halo

The illuminated area extends well beyond the bright object.
