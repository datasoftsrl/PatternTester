# Uniformity

## Purpose

Uniformity patterns reveal brightness and color variations across the display surface.

---

# Typical Uses

- Panel inspection
- Manufacturing QA
- Display aging analysis

---

# Evaluation

Inspect:

- center
- edges
- corners

The display should appear visually uniform.

---

# Common Problems

## Clouding

Localized brighter areas.

---

## Backlight Bleeding

Light leakage near the panel edges.

---

## Dirty Screen Effect

Uneven luminance causing visible patches.

---

## Tinting

Color shifts across different panel regions.

---

# Professional Notes

Uniformity evaluation should be performed in a dark room.

Allow the monitor to warm up before testing.
