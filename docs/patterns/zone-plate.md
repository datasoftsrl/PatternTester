# Zone Plate

## Purpose

The Zone Plate pattern evaluates frequency response, scaling algorithms and aliasing.

It contains concentric sinusoidal structures with continuously increasing spatial frequency.

---

# Typical Uses

- Image processing evaluation
- Scaling verification
- Camera testing
- Video processor validation

---

# Evaluation

A correct system should display:

- smooth concentric rings
- stable image
- no false structures

---

# Common Problems

## Aliasing

False patterns appear at high spatial frequencies.

---

## Ringing

Artificial oscillations appear around transitions.

---

## Moiré

Interference patterns become visible.

---

# Professional Notes

Zone Plate patterns are extremely sensitive to resampling algorithms.

They are commonly used to evaluate image processing pipelines.
