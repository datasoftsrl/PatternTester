# Moiré

## Purpose

The Moiré pattern detects interference generated by repetitive structures.

This test is useful for displays, cameras and image acquisition systems.

---

# Typical Uses

- Camera testing
- Projector evaluation
- Monitor scaling
- Capture card verification

---

# Evaluation

The displayed pattern should remain stable.

No moving waves or interference should appear.

---

# Common Problems

## Moving Bands

Usually indicate aliasing.

---

## Ripple Patterns

Produced by scaling or resampling.

---

## False Colors

Can appear when chroma processing introduces artifacts.

---

# Professional Notes

Moiré patterns are extremely sensitive to scaling algorithms.

Even small changes in image processing may become visible.
