# sRGB

## Purpose

The sRGB pattern verifies the monitor's ability to reproduce the Standard RGB color space.

sRGB is the default color space used by:

- Windows
- Internet
- Office applications
- Most consumer software

---

## Typical Uses

- Web graphics
- General photography
- Office applications
- Consumer displays

---

## Evaluation

Verify:

- primary colors
- neutral gray
- saturation
- color transitions

---

## Expected Result

The display should accurately reproduce the entire sRGB gamut without clipping.

---

## Common Problems

### Oversaturation

Colors appear excessively vivid.
