# Gamma

## Purpose

The Gamma pattern verifies the luminance response of the display.

Gamma defines the relationship between the digital input value and the light emitted by the monitor.

Incorrect gamma affects contrast perception, shadow detail and highlight rendering.

---

# Typical Uses

- Monitor calibration
- Quality control
- Factory verification
- Color critical work

---

# Evaluation

A correct gamma should provide:

- smooth luminance transitions
- balanced midtones
- visible shadow detail
- preserved highlights

---

# Common Problems

## Gamma Too Low

Symptoms:

- washed out image
- low contrast
- gray blacks

---

## Gamma Too High

Symptoms:

- crushed shadows
- excessive contrast
- loss of dark details

---

# Professional Notes

Typical desktop gamma:

- Windows: 2.2
- Linux: 2.2
- macOS: 2.2

Professional workflows may require different target values.
