# Color Uniformity

## Purpose

Color Uniformity evaluates whether neutral colors remain consistent across the entire display surface.

---

# Typical Uses

- Professional monitor evaluation
- Graphic design
- Photography
- Print proofing

---

# Evaluation

Inspect the display using neutral gray.

The entire screen should exhibit:

- identical hue
- identical saturation
- identical brightness

---

# Common Problems

## Corner Tint

Corners exhibit different colors.

---

## Edge Shift

Color changes near display borders.

---

## Center Drift

The center differs from the outer regions.

---

# Professional Notes

Uniformity becomes easier to evaluate in a controlled lighting environment.
