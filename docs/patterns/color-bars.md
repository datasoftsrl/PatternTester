# Color Bars

## Purpose

Color Bars verify color reproduction accuracy.

This pattern is commonly used in broadcast and video production.

---

# Typical Uses

- Display verification
- Capture device testing
- Video pipeline validation
- Broadcast equipment

---

# Expected Result

Each color should appear:

- saturated
- uniform
- clearly separated

No color should bleed into adjacent bars.

---

# Common Problems

- incorrect white balance
- color clipping
- compression artifacts
- chroma subsampling

---

# Professional Notes

Color Bars should be evaluated after grayscale and gamma calibration.
