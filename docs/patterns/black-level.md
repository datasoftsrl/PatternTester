# Black Level

## Purpose

The Black Level pattern determines whether the display correctly reproduces the darkest visible luminance levels.

Correct black level adjustment is essential before evaluating gamma, contrast and grayscale.

---

# Typical Uses

- Monitor calibration
- Television setup
- OLED evaluation
- LCD evaluation
- Projector adjustment

---

# Evaluation

A properly adjusted monitor should display:

- reference black
- first visible gray steps
- uniform dark background

Very dark levels should remain distinguishable.

---

# Common Problems

## Black Crush

Shadow details disappear.

Typical causes:

- excessive contrast
- incorrect gamma
- dynamic contrast
- HDR configuration

---

## Raised Blacks

The image appears washed out.

Black areas become gray.

---

# Professional Notes

Perform the test in a dark room.

Disable:

- Dynamic Contrast
- Black Equalizer
- Adaptive Brightness
