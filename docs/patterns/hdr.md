# HDR (High Dynamic Range)

## Purpose

HDR patterns verify the monitor's ability to reproduce images with a much wider dynamic range than Standard Dynamic Range (SDR).

HDR testing evaluates:

- peak brightness
- shadow detail
- tone mapping
- clipping
- color volume

---

## Typical Uses

- HDR monitor evaluation
- Television calibration
- Professional video production
- HDR10 verification

---

## Evaluation

A properly functioning HDR display should show:

- bright highlights
- preserved shadow details
- smooth transitions
- natural colors

---

## Common Problems

### Tone Clipping

Very bright details disappear.

---

### Raised Black Levels

Dark scenes appear gray.

---

### Incorrect Tone Mapping

Brightness changes abruptly across the image.

---

### Color Compression

Highly saturated colors lose intensity.
