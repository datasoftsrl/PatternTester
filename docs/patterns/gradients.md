# Gradients

## Purpose

Gradient patterns verify the display's ability to reproduce smooth tonal transitions.

They are used to identify color quantization, banding and processing artifacts.

---

# Typical Uses

- Color depth evaluation
- HDR verification
- GPU testing
- Image processing validation

---

# Evaluation

A correct display should show:

- continuous transitions
- no visible steps
- no sudden luminance changes
- uniform gradients

---

# Common Problems

## Banding

Visible steps replace smooth transitions.

Typical causes:

- 6-bit panels
- incorrect gamma
- compression
- poor image processing

---

## Posterization

Large regions merge into a single tone.

Usually caused by excessive processing.

---

# Professional Notes

Gradient evaluation should be performed using native color depth with image enhancements disabled.
