# Dot Pitch

## Purpose

Dot Pitch patterns verify the display's capability to reproduce single-pixel structures.

They are useful for evaluating:

- pixel definition
- scaling accuracy
- panel resolution
- subpixel rendering

---

# Typical Uses

- Native resolution verification
- Pixel structure inspection
- Display comparison

---

# Evaluation

Inspect the pattern closely.

Individual dots should remain:

- clearly separated
- evenly spaced
- perfectly aligned

---

# Common Problems

## Blurred Pixels

Usually caused by scaling.

---

## Missing Pixels

May indicate defective pixels or interpolation.

---

## Uneven Spacing

Can reveal geometry or scaling problems.

---

# Professional Notes

Dot Pitch patterns should always be evaluated using the monitor's native resolution.

Disable image sharpening and scaling whenever possible.
