# Focus

## Purpose

The Focus pattern evaluates the ability of a display to reproduce the finest visible details.

It is particularly useful for:

- LCD monitors
- CRT displays
- Projectors
- Video processors
- Scaling devices

---

# Typical Uses

- Focus adjustment
- Optical evaluation
- Scaling verification
- Signal path validation

---

# Evaluation

Inspect the pattern from the normal viewing distance.

Look for:

- perfectly sharp intersections
- clean vertical lines
- clean horizontal lines
- no smearing

---

# Common Problems

## Soft Image

Possible causes:

- incorrect focus
- monitor scaling
