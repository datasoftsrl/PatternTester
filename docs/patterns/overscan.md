# Overscan

## Purpose

The Overscan pattern determines whether the display crops the outer image area.

Overscan was common in CRT televisions but is generally undesirable on modern digital displays.

---

# Typical Uses

- Television setup
- HDMI verification
- Media player testing
- Console calibration

---

# Evaluation

All outer borders should remain completely visible.

Corner markers must appear without clipping.

---

# Common Problems

## Cropped Borders

Part of the image disappears outside the visible area.

---

## Incorrect Scaling

The image fills the screen by enlarging beyond its native dimensions.

---

# Professional Notes

Modern monitors should normally operate with 1:1 pixel mapping and no overscan.
