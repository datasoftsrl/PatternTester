# PatternTester

> Professional Monitor Test Pattern Generator

PatternTester is an open-source application designed to evaluate, verify and analyze the performance of display devices using professional test patterns.

The project is intended for:

- Display manufacturers
- System integrators
- Service technicians
- Quality control laboratories
- AV professionals
- Enthusiasts and retro-computing users

---

## Key Features

- Cross-platform (Windows / Linux)
- Multi-monitor support, including mixed per-monitor display scaling
- Native Avalonia UI, with a selectable light/dark theme
- Real-time pattern rendering at native monitor resolution
- High-DPI aware
- Portable, per-user JSON configuration
- Open Source (GPL v3)

---

## Built-in Patterns

- Geometry
- Single Color
- Gray
- Gamma
- Bars
- Color Bars
- Gradient to Black
- Two-Color Gradient
- Chessboard
- Phase
- Color Temperature

See the [Pattern Reference](patterns.md) for what each one checks — and for a broader library of display-testing background reading, including topics not yet implemented as dedicated patterns.

---

## Project Goals

PatternTester has been designed with four main objectives:

1. Professional monitor testing
2. Cross-platform compatibility
3. Clean software architecture
4. Long-term maintainability

The software is not only a pattern generator but also a technical reference for monitor testing and calibration.
