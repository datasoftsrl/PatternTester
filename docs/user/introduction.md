# Introduction

## Welcome

PatternTester is a monitor test pattern generator for display evaluation, calibration checks and quality control. It can be used with LCD, OLED, MiniLED and CRT monitors, TVs, projectors, video processors and capture devices — anything that accepts a standard video signal from a Windows or Linux PC.

The application generates fullscreen test patterns to help evaluate geometry, gamma, color reproduction and general display behavior.

---

## Main Features

- Fullscreen pattern generator, one monitor at a time or across several simultaneously
- Multi-monitor support, including mixed display-scaling setups on Windows
- Native resolution output on the target monitor
- 11 built-in test patterns (see the [Pattern Reference](../patterns.md))
- Light and dark application theme
- Italian and English interface, with additional languages addable via a simple JSON file (see [External Languages](../PatternTester_Lingue.md))

---

## Intended Audience

- Home users and enthusiasts
- Photographers and video editors
- Display reviewers
- Service technicians and AV integrators
- Quality assurance / quality control workflows

---

## Requirements

- Windows 10/11 or a Linux distribution with a graphical desktop (X11-based; see [Linux notes](../linux.md))
- A GPU/driver capable of the monitor's native resolution
- No internet connection required — PatternTester runs entirely offline
