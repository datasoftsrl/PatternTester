# First Start

When PatternTester starts, the **Main Window** appears — a compact control panel with a menu bar at the top and, below it, a panel showing the parameters for whichever pattern is currently selected.

---

## Selecting a Monitor

If more than one display is connected, choose the target monitor from **Display → Monitor** before showing a pattern fullscreen. Not sure which physical screen is which? Use **View → Identify Monitors** — see [Identifying Monitors](../user.md#identifying-monitors) in the User Guide.

---

## Choosing and Configuring a Pattern

1. Pick a test from the **Pattern** menu.
2. The configuration panel below the menu bar updates automatically to show that pattern's parameters (for example, gamma value and grid size for Gamma; direction for a gradient).
3. Adjust the parameters as needed — changes apply live once the pattern is shown.

---

## Showing and Leaving Fullscreen

- **View → Show Pattern** displays the pattern fullscreen, above every other window, on the monitor selected in step 1.
- To go back to the controls, **right-click** anywhere on the fullscreen pattern, or untick **View → Show Pattern** again from the main window.

---

## Before You Start Evaluating

For more consistent results:

- Let the monitor warm up for a few minutes.
- Disable dynamic contrast and automatic/adaptive brightness where possible.
- Reset any picture "enhancement" modes (sharpening, motion smoothing) to neutral.
- Use the monitor's native resolution.
