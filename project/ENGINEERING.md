# PatternTester Engineering Guidelines

## Project Vision

PatternTester is a professional, cross-platform monitor test pattern generator designed for Windows and Linux.

## Engineering Principles

- Open Source first.
- Cross-platform by design.
- Offline first.
- Documentation is part of the project.
- English source code only.
- Simplicity over complexity.
- Maintainability first.

## Coding Rules

- All comments must be written in English.
- Public APIs should include XML documentation.
- No duplicated code.
- Prefer small and safe refactoring.
- Keep platform-specific code isolated.

## Platform Support

Primary targets:

- Windows 10/11
- Linux (X11)
- Linux (Wayland where supported)

## Build System

- .NET 10
- Git
- VS Code
- Visual Studio
- MkDocs Material

## Documentation

Documentation is maintained together with the source code.

## Long-Term Goal

Produce a clean, maintainable and professional open-source project.
